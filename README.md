# EaglePrtSc

Windows 桌面工具（v5.14）：双击 PrtSc 保存原生全屏截图到 Eagle；长按开始/停止全屏录制，保存 MP4 后自动导入 Eagle。EXE 提供中文设置界面。

已发布版：**[下载 v5.14 便携包（含 EXE）](https://github.com/Porco24/EaglePrtSc/releases/download/v5.14/EaglePrtSc-v5.14.zip)**，也可查看 [Releases](https://github.com/Porco24/EaglePrtSc/releases)。解压后打开 `EaglePrtSc.exe`；首次启动自动检查并安装缺少的 FFmpeg / ffprobe。Eagle 需单独安装并运行。

## 功能

- 双击窗口为 450 毫秒；单击延迟约 450 毫秒执行原生 PrtSc。
- 长按约 800 毫秒开始录制，再次长按停止，松开后不会误触发截图。
- 图片可选 PNG / JPEG、10–100% 分辨率比例及 JPEG 质量。
- 视频可设置 10–100% 分辨率比例、1–200 fps（整数）、0.5–100 Mbps 目标码率。
- 默认使用画质优先（CQP / CRF 20），优先 NVIDIA NVENC；没有可用的 NVENC 时自动回退到 x264 veryfast。可手动选择编码器与目标码率模式。
- 单显示器全屏优先 DXGI Desktop Duplication；原分辨率、未开启锐化的 NVENC 录制使用显卡纹理直接编码，失败时回退到 CPU 处理 / GDI。多显示器继续采集完整虚拟桌面。显示鼠标的选择保留。
- 缩放明确使用 Lanczos；新增 0–100% 亮度锐化，默认关闭，可按画面尝试 10–20%。
- 默认 60 fps，并开启码率“自动计算”：分辨率比例 / FPS 改变时，右侧推荐参考值同步更新；每次开始录制时按实际桌面重新计算。目标码率模式使用该值；画质优先模式按画面内容分配码率。目标码率模式下关闭“自动计算”后可手动填写，参数调整时保留手填值；点击推荐值可以重新启用自动计算。
- SDR 桌面颜色写入与真实转换一致的矩阵 / 范围 / 原色 / sRGB 传递曲线标记，防止播放器猜测颜色。CPU 路径使用 BT.709 矩阵，NVENC 原生 RGB 路径保留其实际 BT.601 矩阵；均为有限范围 YUV，MP4 保留标记。
- 声音可选电脑声音或静音；电脑声音可设置 0–200% 音量和 AAC 音频码率。
- 通过 WASAPI 回环录制默认播放设备的电脑声音，始终不打开麦克风；鼠标显示可单独开关。
- 设置保存到本地；下一次截图 / 录制生效，当前录制使用启动时的参数。
- 显示录制计时与无声状态提示，不抢焦点；支持 Windows 的捕获排除。截图、录制开始 / 保存及导入通知不播放提示音，避免混入电脑声音录制。
- 截图、视频处理与 Eagle 导入分开执行，导入期间可以继续使用。
- 上传前完整解码检查 H.264 / AAC 视频；确认入库并完成校验后自动清理本地缓存，失败时保留原文件。
- 检测 Eagle 接口返回列表中的重复素材 ID，异常时暂停提交和缓存清理，新截图 / 录像继续保存在本地；索引恢复后自动继续。
- 双击 EXE 或托盘图标打开设置；关闭窗口后继续在托盘运行。托盘支持重试、查看本地文件和退出；可选开机启动。
- “连接与文件”页可直接勾选 / 取消登录 Windows 自动启动，保存后完成注册 / 移除，无需运行脚本；会读取现有注册状态。
- 首次启动自动检查 FFmpeg / ffprobe，复用已有安装，缺少或无法运行时下载、校验并安装到本目录，无需管理员权限；设置页显示进度并支持重试。

## 统一视频设置

视频与画质 / 性能选项合并在同一个“视频”页。分辨率和 FPS 始终显示；选择“画质优先”时仅显示画质等级，选择“目标码率”时仅显示码率及自动计算 / 手动输入。切换模式保留各自值；下方统一设置编码器、采集方式、锐化、声音和鼠标。保存后从下一段录制生效。

## 默认参数

| 项目 | 默认值 |
| --- | --- |
| 图片 | PNG、100% 分辨率；JPEG 质量 90（切换后生效） |
| 视频 | 100% 分辨率、60 fps、自动计算推荐码率、H.264 |
| 声音 | 默认播放设备的电脑声音、100% 音量、AAC 192 kbps 立体声 |
| 鼠标 / 麦克风 | 隐藏鼠标；不录麦克风 |

分辨率比例分别作用于宽和高。例如 3440 × 1440 设置 50% 后输出 1720 × 720；视频尺寸会向下调整为偶数。界面显示当前桌面对应的输出尺寸和估算体积；目标码率及文件体积会随画面复杂度变化。

推荐码率参考 [YouTube 的 H.264 SDR 上传建议](https://support.google.com/youtube/answer/1722171?hl=en) 中的 30 / 60 fps 档位；对非标准分辨率、宽屏、其他帧率按像素数和帧率估算，并向上取整到 0.5 Mbps。这是本工具的画质 / 体积建议，不是官方的桌面录屏标准；推荐范围限制为 0.5–100 Mbps。例如 3440 × 1440、60 fps 推荐 32.5 Mbps；同屏 50% 缩放（1720 × 720）、60 fps 推荐 10.5 Mbps。

首次使用和“恢复默认参数”会采用 60 fps 并开启码率自动计算。`AutoVideoBitrate` 保存选择的自动 / 手动模式；开启时，JSON 中的 `VideoMbps` 只是当时的显示值，不会作为下一段录制的固定码率。录制开始时会用当前实际输出分辨率和 FPS 计算；已开始的录制保持参数快照。

画质优先模式下，仅显示画质等级；实际码率随内容变化，取消最大码率限制，文件体积无法只根据分辨率 / FPS 精确计算。码率设置在后台保留，切回目标码率时显示。目标码率模式保留已有推荐与手动值，NVENC 使用 VBR 并允许最高两倍目标码率的短时峰值；x264 使用 ABR + VBV。

自动计算模式下，码率输入框不可手动编辑。目标码率模式下关闭后输入框启用，已有手动保存的码率正常保留；右侧继续显示对应参数下的建议，点击可以切回自动计算。显示器分辨率变化时界面提示也会更新。旧设置没有自动 / 手动标记时，匹配当前推荐值的设置启用自动；其他手填值按手动模式保留。`--apply-video-defaults` 可单独将已保存视频参数更新为 60 fps 并启用自动计算，保留其他设置。

## 环境

Windows x64、.NET Framework 4.x、Eagle 的本地 API（`127.0.0.1:41595`），以及支持 `gdigrab`、`libx264` 和 AAC 的 FFmpeg/FFprobe。

已在 Windows 10 22H2、3440 × 1440 桌面上生成有效视频。其他显示器布局和 Windows 版本尚未逐一实测。

## 使用

1. 下载便携包并解压到固定目录，安装 Eagle。FFmpeg / FFprobe 在首次启动时自动安装，无需提前安装。已带 EXE 的包可以直接跳到第 3 步。源代码版本需要先双击 `Build.cmd`，或在 PowerShell 执行：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1 -Validate
   ```

2. 源代码版本可用脚本配置安装路径。FFmpeg 在 PATH 中时会自动发现；也可以显式指定：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\Configure.ps1 -EaglePath 'C:\Program Files\Eagle\Eagle.exe' -FFmpegPath 'C:\Tools\ffmpeg\bin\ffmpeg.exe'
   ```

   FFprobe 默认从 FFmpeg 同目录查找，也支持 `-FFprobePath`。

3. 在 Windows 资源管理器中双击 `EaglePrtSc.exe`。缺少录制依赖时自动下载安装，进度显示在“连接与文件”页，完成后填入路径。已有安装会直接复用；也可手动指定 FFmpeg / FFprobe。该页仍可选择 Eagle 的 EXE 安装位置，点击“保存设置”。下载期间可以继续截图，录制在依赖就绪后使用。
4. 打开需要接收素材的 Eagle 库。设置界面可随时关闭，工具继续在托盘运行。
5. 双击 PrtSc 截图；长按约 0.8 秒开始录制，再次长按停止。调整设置后点击保存，下一次操作生效。

已有旧版本运行时，先在资源管理器中双击 `Start.cmd` 完成重启。若目录内有 `EaglePrtSc.update`，脚本会先正常停止旧版并等待释放，再校验产品标识、原子替换 EXE 并核对 SHA-256。启动后清理旧版备份。之后双击 EXE、托盘图标或托盘的“设置…”都能打开设置页。`--background` 可以仅启动后台监听；新建的开机启动快捷方式使用该参数。

注册开机启动：打开 EXE → “连接与文件” → 勾选“登录 Windows 时自动启动（后台运行）” → 保存设置。取消勾选并保存即可取消注册，当前程序继续运行。不会在打开 EXE 时未经设置自动新增注册。

注册状态从 Windows 启动快捷方式读取；启动参数为 `--background`，登录后不弹出设置窗口。已注册的旧快捷方式若没有后台参数，在保持勾选并保存时升级为后台启动。若同名启动快捷方式指向另一个安装目录，保留它并说明原因。

兼容脚本：`EnableStartup.cmd` 注册；`DisableStartup.cmd` 取消注册并退出。`Start.cmd` 只负责立即启动 / 重启，不负责注册。已注册时，更新原目录中的 EXE 后仍能开机启动。退出：托盘菜单或 `Stop.cmd`。启动快捷方式指向本目录，启用后请保持目录位置稳定。

更新前先退出运行中的工具，再重新构建并启动。退出时会先保存正在录制的视频；重启脚本最多等待旧进程 60 秒。

## 本地文件

`Pending/` 保存待导入的截图和视频，入库确认后自动清理；导入失败时保留文件，可从托盘重试。

`settings.json` 保存默认参数和安装路径，写入时保留上一版 `settings.json.bak`；读取失败时使用默认值并保留原文件。旧版的 `eagle-path.txt` / `ffmpeg-path.txt` / `ffprobe-path.txt` 会作为首次设置的来源。

`RecordingWork/` 存储临时画面和系统录音；有效 MP4 生成后清理当次中间文件。断电或处理失败时保留中间文件，不把不完整视频导入 Eagle。

## 限制

- 使用录制开始时的默认播放设备；切换或拔掉设备前应先停止录制。
- WASAPI WAV 中间文件上限约 4 GB，长时间录制请分段。
- 录制热键需要正常交付按下/松开事件的 PrtSc 键；其他工具占用热键可能干扰操作。
- 当前录制路径面向 SDR；未实现 HDR 浮点采集及 HDR 到 SDR 色调映射。开启 Windows / 游戏 HDR 时不能保证颜色一致。
- 远程桌面、受保护内容和硬件加速窗口的画面需要按实际环境验证。
- FPS 设置为目标值；实际画面采集速度受桌面、显示设备和 CPU 编码能力影响。200 fps 已用合成画面验证编码参数。

## 验证

v5.6 对照：同一 2 秒 3440×1440 / 60 fps 合成运动画面，旧 x264 ultrafast + 32.5 Mbps 上限的平均 PSNR 为 42.11 dB，新 NVENC P5 / CQP 20 为 46.88 dB；文件分别约 8.68 MB 和 13.49 MB。新片段解码得到 120 个不同帧。此结果只覆盖测试内容，不代表所有游戏的画质、码率或采集性能。NVENC 及回退软件路径、颜色、声音、15 / 60 / 200 fps 合成录制已验证。

当前录制路径已通过正常用户桌面的 CPU / GPU 60 fps 实录、GPU 30 fps 静音目标码率、缩放回退、色块往返与完整解码测试。不同游戏场景的持续流畅度仍需实录验证，日志会记录实际采集后端。

## v5.14 音频连续性修复

系统声音按 WASAPI 设备的采样位置连续拼接，仅用首包时间戳对齐音画起点。避免逐包按 QPC 时间戳补零 / 裁采样造成爆音，同时保留真实静音间隔和缺失帧。录音线程使用 Windows 的 MMCSS Audio 调度，重复使用采样缓冲区，并在写入磁盘前归还声卡缓冲区。

`activity.log` 中的 `AUDIO_TIMING` 和录制信息中的 `audioDiagnostics` 记录设备断流、缺失 / 重复采样及时间戳错误。`--test-audio-timeline <目录>` 验证 44.1 / 48 kHz 的连续采样、时间戳抖动、静音、缺帧和设备位置重置，不播放声音或导入素材。

## GPU 录制性能优化

原分辨率、未开启锐化的 NVENC 录制直接使用 D3D11 纹理，避免画面下载到 CPU 后再上传到显卡。采集上限留有少量调度余量，最终输出 FPS、CQP / 目标码率和编码质量参数继续按设置执行。启动时确认已有编码帧后才认为后端可用；GPU 初始化失败会自动回退。

开启缩放、锐化、手动 GDI、软件编码或使用多显示器时，保留相应处理路径。已有参数不会被更新覆盖；日志中的 `capture=DXGI-GPU` 表示正在使用显卡直接编码。

`Build.ps1 -Validate` 运行按键时序、导入队列、持久化导入恢复、缓存清理、开机启动快捷方式和推荐码率检查，不触发真实截图、录制或导入。清理和开机启动检查仅使用独立测试目录，不会修改真正的 Windows 启动目录；验证注册 / 移除、后台参数、旧版快捷方式迁移及其他安装目录保护。推荐码率检查覆盖默认 60 fps、标准 / 宽屏 / 缩放分辨率、范围限制、自动 / 手动模式持久化、忽略缓存码率并按实际分辨率计算，以及界面自动跟随参数、手动值保留和点击切回自动。

配置 FFmpeg / FFprobe 后，可使用 `Build.ps1 -Validate -ValidateMedia` 检查设置持久化和备份、PNG / JPEG、缩放、15 / 60 / 200 帧、静音音轨、系统声音、录制参数快照，以及编码后的音量。颜色检查用 RGB 色块编码后解码，覆盖黑白、16 级灰阶与 16 种颜色，以及 SD / HD / 缩放输出；检查 MKV 和 MP4 的颜色标记及 RGB 通道误差。该媒体检查使用合成画面，并会短暂采集电脑播放声音，结果保留在 `.build/`；不会导入 Eagle。

源代码中另有媒体合成和录制诊断入口，用于开发调试；真实桌面采集需要在正常 Windows 桌面执行。录制会采集系统播放声音。

## 实现

- `EaglePrtSc.cs`：键盘钩子、托盘、提示、后台队列和 Eagle 导入验证。
- `Recording.cs`：WASAPI 回环、音频时间轴、FFmpeg 录制与 MP4 合成。
- `Settings.cs`：默认参数、设置界面、持久化、图片处理及媒体参数检查。
- `Build.ps1`、`Configure.ps1`：本地构建和安装路径配置。
- `Dependencies.cs`：首次启动依赖检查、校验、安装和失败重试。

接口资料：[Eagle addFromPath](https://api.eagle.cool/item/add-from-path)、[FFmpeg gdigrab](https://ffmpeg.org/ffmpeg-devices.html#gdigrab)、[Windows WASAPI loopback](https://learn.microsoft.com/en-us/windows/win32/coreaudio/loopback-recording)。

## v5.10 图片预览与索引异常保护

图片与视频都要求 Eagle 完成解析。图片必须有有效宽高，且 noPreview / noThumbnail 不能为 true；即使旧版已经写入确认记录，也要再次满足此条件才能清理缓存。图片解析停滞时等待，不自动堆积缩略图刷新任务。

在当前接口返回的 100 条素材中检测重复 ID。发现同一 ID 出现两次，暂停新的 addFromPath 请求与已确认缓存清理，并提示“Eagle 索引异常，原文件已保留”。仍可截图和录制，索引恢复后任务自动继续。此检查不扫描整个大库，也不修改 Eagle 的索引或库内原件。

## v5.11 自动安装录制依赖

首次启动（包含后台启动）异步检查 FFmpeg 与 ffprobe。按设置、旧路径记录、同目录 ffprobe、程序私有工具目录和 PATH 查找；已有可运行的工具直接复用。缺少或无法运行时使用 Gyan 的 GitHub 官方镜像最新 release essentials ZIP，核对 GitHub 发布记录提供的 SHA-256 后解压并检查版本、libx264 / AAC 编码器以及 gdigrab / ddagrab。

安装到 `Tools/ffmpeg/<SHA-256>/bin/`，校验成功才原子写入 `current.json` 激活；保留上一个有效安装。解压仅接受配套的两份 EXE 和许可证 / 说明文件，不执行安装脚本。保留 GPLv3 许可证及来源链接，不修改系统 PATH。安装过程不影响截图，录制必须等待就绪。设置页提供“检查／安装录制依赖”按钮，显示检查、下载百分比、完成或失败重试；下载失败后下次启动也会重试。

安装结束时只更新下载期间未被用户改动的工具路径。离线环境可手动选择已有 FFmpeg / ffprobe。依赖安装与注册开机启动分别处理，仍通过设置中的开机启动勾选项注册。

下载来源：[Gyan 官方构建](https://www.gyan.dev/ffmpeg/builds/) 和 [官方 GitHub 镜像](https://github.com/GyanD/codexffmpeg/releases)，由 [FFmpeg 下载页](https://ffmpeg.org/download.html) 列出。`Build.ps1 -Validate` 包含依赖安装隔离测试；实际联网安装测试需正常用户会话的 HTTPS 环境。

## v5.12 无声反馈

移除截图、录制开始与视频保存的提示音。导入及录制错误通知使用无声状态提示；错误提示保留五秒。文字反馈与录制计时继续显示，已保存的视频参数保持不变。
